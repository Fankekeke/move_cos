# 基于 SpringBoot + Vue 的搬家服务系统 (Moving Service System)

在线预约 · 智能估价 · 实时追踪 · 支付宝支付 · 订单管理 · 评价反馈 · 多角色协同

本项目是一套面向同城搬家服务场景的在线预约与管理系统，采用前后端分离架构，覆盖管理员、员工（搬家师傅）与普通用户三类角色。系统围绕“搬家预约、智能估价、订单管理、支付记录、员工调度、评价管理、公告通知、个人信息”等核心业务设计，支持用户在线填写起终点、楼层及物品清单，系统根据计费规则实时测算费用并一键下单，员工接收任务并更新服务进度，管理员完成全局运营管控、计费规则配置、订单调度与服务质量监督，适用于同城搬家平台、货运跑腿服务平台、社区搬家服务系统及搬家公司数字化管理平台。

## 核心特性

- **多角色权限管理**：区分管理员、员工（搬家师傅）与普通用户三类角色，实现不同权限隔离与功能访问控制。
- **智能估价引擎**：灵活配置公里数、楼层、大件物品、特殊时段等计费规则，用户填写搬家需求后系统自动实时测算费用，收费透明。
- **搬家在线预约**：用户在线填写起终点地址、楼层信息、物品清单与预约时间，系统一键生成订单，简化下单流程。
- **订单实时追踪**：用户可实时查看搬家任务当前状态与师傅位置，全程掌握服务进度，确保搬运过程可视化。
- **支付宝在线支付**：集成支付宝支付能力，支持用户在线缴纳搬家费用，支付后自动生成缴费记录，便于查询与对账。
- **员工调度管理**：管理员可分配搬家任务给员工，员工接收任务后更新服务状态（已接单、已到达、搬运中、已完成）。
- **评价管理中心**：用户服务完成后可对师傅的专业度、准时性、服务态度等进行评分与文字评价，作为员工考核依据。
- **公告与消息通知**：管理员发布平台政策与活动公告，系统通过消息推送触达用户及员工，确保关键信息高效传递。
- **实名认证与信用体系**：对用户与员工进行实名认证，建立信用评分机制，保障平台服务安全可靠。

## 功能模块概览

## 管理员端：全局运营与规则管控

管理员负责平台整体运营、规则配置、订单调度、用户与员工管理及服务质量监督：

### 公告与消息通知

- **公告管理**：发布平台政策、活动动态、服务调整、维护通知等系统公告，支持置顶与定时发布。
- **消息通知**：向用户及员工推送订单状态变更、任务分配、缴费提醒、评价回复等重要消息，确保信息高效触达。

### 用户与员工管理

- **用户管理**：管理注册用户信息，包括账号状态、实名认证、联系方式、收货地址，支持禁用异常账号与重置密码。
- **员工管理**：维护搬家师傅档案，包括姓名、手机号、身份证号、驾驶证/从业资质、信用评分、服务评级，支持员工状态管理与权限分配。

### 计费规则配置

- **计算规则配置**：灵活设定基础起步价、公里数单价、楼层费（有无电梯）、大件物品附加费、特殊时段（晚间/夜间/节假日）加收比例等计费标准，实现系统自动估价，确保收费流程透明。

### 订单与支付管理

- **订单管理**：实时监控订单全生命周期，包括待支付、待接单、已接单、搬运中、已完成、已取消等状态，支持订单筛选、详情查看、手动派单与异常处理。
- **支付管理**：详细记录每一笔资金流水，包括支付金额、支付方式、支付时间、交易流水号，支持财务对账与退款处理。

### 评价与数据中心

- **评价管理中心**：收集并审核用户对服务的反馈评价，查看评分分布与文字评论，作为员工绩效考核与服务质量改进的依据。
- **数据统计**（可选扩展）：展示平台核心运营指标，包括日/月订单量、收入总额、热门服务类型、员工服务排行等，辅助经营决策。

---

## 员工端：任务执行与服务反馈

员工（搬家师傅）负责接收搬家任务、执行服务并更新订单状态：

### 个人信息与任务管理

- **个人信息**：查看与维护个人档案，包括姓名、联系方式、资质证件、信用评分与服务评级。
- **任务列表**：查看分配给自己的搬家任务，包括订单详情、起终点地址、楼层信息、物品清单、预约时间与客户联系方式。

### 订单状态更新

- **状态更新**：一键更新订单服务状态，包括已接单、已出发、已到达出发地、搬运中、运输中、已到达目的地、已完成，便于用户实时追踪进度。

### 消息通知

- **我的消息**：接收新任务分配、订单状态变更、用户评价等消息通知，支持标记已读。

---

## 用户端：便捷预约与消费追踪

用户端面向普通注册用户，提供注册登录、搬家预约、订单追踪、在线支付与评价反馈功能：

### 账户与个人信息

- **登录注册**：支持手机号、邮箱等方式注册登录，密码加密存储，支持实名认证。
- **个人信息**：维护昵称、手机号、头像、常用地址（出发地/目的地）等个人信息，支持地址簿管理。

### 搬家预约与下单

- **搬家填写预约**：在线填写出发地、目的地、楼层信息（有无电梯）、物品清单（家具、家电、箱包等）、预约时间，系统根据计费规则实时测算费用，用户确认后一键提交订单。

### 订单追踪与支付

- **我的订单追踪**：查看个人所有订单，包括待支付、待接单、搬运中、已完成等状态，实时查看订单当前进度与师傅位置，全程掌握服务动态。
- **付款记录**：查看历史支付记录，包括支付金额、支付方式、支付时间与关联订单，让每一笔搬家支出清晰可查。
- **支付宝在线支付**：对搬家订单进行在线支付，支持支付宝快捷缴费，支付成功后自动生成电子缴费凭证。

### 评价与反馈

- **订单服务评价**：搬家服务完成后，对师傅的专业度、准时性、服务态度、物品保护情况等进行星级评分与文字评价，通过真实反馈提升平台整体服务水准。
